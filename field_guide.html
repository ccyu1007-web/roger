席勒PE警示 ▼
欄位說明來源
10年均EPS最近10~11年EPS簡單平均計算 financial_annual 歷史EPS
最少7年才計算
席勒PE股價 / 10年均EPS計算
席勒警示綜合PE / 席勒PE 計算
< 0.5：紅色警示 — 近幾年EPS可能處於循環高峰，綜合PE是「假便宜」
0.5 ~ 1.5：綠色正常 — 估值判斷可信
> 2.0：可能在循環低點，反而是機會
定位：異常偵測器，不是估值工具。只在異常時跳警示，不干擾綜合PE判斷
聶夫總報酬率法 ▼
欄位說明來源
5年端點CAGR(最新EPS/5年前EPS)^(1/5)-1計算
只用EPS>0的年份，虧損年跳過
5年平滑CAGR(近3年均值/遠3年均值)^(1/5)-1計算
含虧損年，用平均抑制雜訊
3年端點CAGR(最新EPS/3年前EPS)^(1/3)-1計算
3年平滑CAGR(近2年均值/遠2年均值)^(1/3)-1計算
營收CAGR5年營收複合成長率計算 (最新年營收/5年前營收)^(1/5)-1
封頂20%，不受業外損益影響
Neff比率總報酬率 / PE 計算 (營收CAGR + 殖利率) / PE
PE = 股價 / 綜合EPS（有預估用預估）
殖利率 = 綜合股利 / 股價（有預估用預估）
≥ 1.0 紅色粗體（好訊號）
< 1.0 灰色
林區PEG法 ▼
欄位說明來源
一致性成長穩定度（月營收60筆+季EPS 20筆） 計算 0.30×正成長月比例 + 0.25×波動度 + 0.25×連續衰退 + 0.20×季EPS正成長
≥ 0.5：非循環股，PEG可信
< 0.5：循環股警示，PEG僅供參考
PEGNeff比率的倒數 計算 PE / (營收CAGR + 殖利率)
≤ 1.0 紅色粗體（好訊號）
> 1.0 灰色

灰色標記 = 「數字算得出來，但方法論認為不適用這支股票」
