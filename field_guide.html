聶夫總報酬率法 (John Neff) ▼
欄位說明計算方式 / 來源
端點CAGR EPS 頭尾複合年成長率（方法一） 計算 (最新EPS / 最早EPS)^(1/n) - 1
n = 實際年份差（成長段數）。簡單直接，但起點或終點若為異常年份會被扭曲。
平滑CAGR 3年平均對3年平均的 CAGR（方法二） 計算 (近3年EPS平均 / 遠3年EPS平均)^(1/中點差) - 1
用3年平均抑制景氣循環雜訊，適合EPS波動大的公司。需要7~9年資料。兩種方法差距大代表成長不穩定。
保守成長率 兩種方法取較低者 計算 min(端點CAGR, 平滑CAGR)
取 min 本身就是保守動作（在兩個合理數字中選較不樂觀的）。
不需要額外乘折扣係數，保守由低本益比提供安全邊際。
Neff比率 總報酬率與本益比的比值，越高越具投資價值 計算 (保守成長率 + 殖利率) / PE
判斷標準：
≥ 1.3：顯著低估（紅色）
0.9 ~ 1.3：合理偏低（橘色）
0.7 ~ 0.9：中性
< 0.7：偏貴（灰色）
聶夫的取捨原則
成長率範圍聶夫的態度原因
< 7%成長太弱，不適用此法被通膨吃掉，成長無意義（灰色標記）
7% ~ 12%甜蜜點（主力投資區）可預測、可持續，聶夫最愛
12% ~ 20%可投資但需警惕成長可能不持續，要求更便宜的價格
> 20%不可預測，放棄無法可靠預測，直接灰色標記
五層內建保守機制
#機制說明
1取 min在兩個合理的歷史數字中選較不樂觀的
220% 硬上限超過 20% 直接灰色標記，不評估
3營收驗證EPS 成長 > 營收成長 ×1.5 → 警示（利潤率變化）
4低本益比用低 PE 買進本身就是最大的安全邊際
5總報酬門檻Neff 比率 >= 0.7 才值得關注
殖利率來源：預估股利 / 股價（優先用個股自訂，無則用沈董股利）
PE來源：股價 / 預估EPS（優先用個股自訂，無則用沈董EPS）
品質判斷請搭配「財務等級」和「體質檢查表」，不在聶夫公式內重複做
林區PEG法 (Peter Lynch) ▼
欄位說明計算方式 / 來源
端點CAGR 同聶夫的端點 EPS CAGR 計算 同聶夫的端點CAGR
林區與聶夫共用同一個端點CAGR數據
算術平均 過去5年EPS逐年成長率的簡單平均（林區用） 計算 Σ(各年EPS YoY成長率) / 年數
例：5年個別成長率為 10%, 15%, 8%, 12%, 20%，算術平均 = 13%
一致性 成長品質指標：算術平均與CAGR的吻合度 計算 1 - |算術平均 - CAGR| / CAGR
判斷標準：
≥ 0.9：極穩定成長，PEG可信度高（綠色）
0.5 ~ 0.9：穩定，正常使用
< 0.5：景氣循環股，不適用PEG（灰色標記）
林區的洞見：算術平均 >> CAGR 時，代表 EPS 波動劇烈，是景氣循環股而非成長股
PEG 本益比成長比，越低代表成長性相對股價越便宜 計算 PE / (保守成長率 + 殖利率)
判斷標準：
≤ 1.0：低估，值得關注（紅色）
1.0 ~ 1.5：合理偏貴（橘色）
> 1.5：偏貴（灰色）
林區修正版：將殖利率加入分母，對高配息公司更公平（傳統PEG = PE / 成長率）
聶夫 vs 林區 的關係
Neff比率 = (保守成長率 + 殖利率) / PE
PEG = PE / (保守成長率 + 殖利率)
兩者互為倒數：Neff比率 = 1 / PEG

差異在於輔助判斷：
聶夫用「5年CAGR vs 3年CAGR」判斷成長是否減速
林區用「算術平均 vs CAGR」判斷成長是否穩定（排除景氣循環股）
聶夫/林區 灰色標記說明 ▼
什麼是灰色標記？
灰色標記代表「數字算得出來，但方法論本身認為不適用這支股票」。
即使 Neff 比率或 PEG 的數字看起來符合標準，灰色標記提醒你這個結果要打問號。
灰色條件原因來自誰的規則
保守成長率 < 7% 成長太弱，被通膨吃掉就沒意義了，聶夫法不適用 聶夫（John Neff）
聶夫主力投資區是 7%~12%，低於 7% 不值得用總報酬率法分析
5年CAGR > 20% 成長率不可持續、無法可靠預測，直接放棄不評估 聶夫（John Neff）
「成長率超過 20%，無法可靠預測，直接放棄。」
成長一致性 < 0.5 算術平均和 CAGR 差距太大，代表 EPS 波動劇烈，是景氣循環股而非成長股，PEG 估值無意義 林區（Peter Lynch）
「算術平均看起來像高成長，但 CAGR 很低——這是景氣循環股，不是成長股！」
