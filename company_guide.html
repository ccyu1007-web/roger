#條件判定邏輯
1財務等級 A級 >= 3年近5年有3年以上 A級（AA/A1/A2/B1A/B2A），且近2年都 A級以上
從 stocks 表 fin_grade_1~5 讀取，後端 _refresh_fin_grades() 用 ROIC 矩陣計算
2營益率 >= 10% 達3年近5年有3年營益率>=10%，且近2年>=10%
從 financial_annual 讀取 operating_income/revenue 計算
3累積營收年增率 >= 0%stocks 表 revenue_cum_yoy 欄位
4最近一季毛利率變化 > 0最新季毛利率 - 前一季毛利率 > 0
從 quarterly_financial 讀取 gross_profit/revenue
5最佳等級達 AA各種EPS（預估/系統/沈董/綜合/加權/近四季）× 最低PE，至少一個 >= 股價
detail 列出每種 EPS 來源名稱和計算值
6股價低於 AA 門檻收盤價 <= val_aa + 0.005
val_aa 由後端 recalc_all_derived() 統一計算存 DB

8綜合殖利率 >= 6%stocks 表 blend_yld 欄位
9配息率 50%~85%stocks 表 weighted_payout 欄位
10DDM年報酬 >= 10%EPS 優先順序：預估 > 系統 > 沈董。PE 預設14，股利=綜合股利×3年
年報酬 = ((EPS×PE + 三年股利) / 現價) ^ (1/3) - 1
成長加分（8 項）
#條件判定邏輯
115年營收CAGR >= 7%(最新年營收/5年前營收)^(1/5)-1
封頂20%，不受業外損益影響
12聶夫 Neff 比率 >= 1.0(營收CAGR + 殖利率) / PE
PE/殖利率來源：預估 > min(沈董, 系統預估)
13林區 PEG <= 1.0PE / (營收CAGR + 殖利率)
Neff 比率的倒數
14林區成長一致性 >= 0.5月營收60筆 + 季EPS 20筆綜合判斷
0.30×正成長月比例 + 0.25×波動度 + 0.25×連續衰退 + 0.20×季EPS正成長
15趨勢燈號為綠色3M/12M累計營收年增率 + EPS趨勢 + 存貨風險
綠=成長、黃=持平、紅=衰退
16席勒警示 >= 0.5綜合PE / 席勒PE，席勒PE = 股價 / 10年均EPS
< 0.5 紅色警示（循環高點假便宜）；EPS不足7年預設通過
17ROIC 未連續3年下滑近3年 ROIC 是否每年都比前一年低
從 financial_annual 讀取歷史 ROIC
18毛利率近3年降幅 < 3pp3年前毛利率 - 最新毛利率 < 3個百分點
從 financial_annual 讀取歷史毛利率

年度財報 ▼
欄位來源說明
財務體質等級計算ROIC版矩陣（後端計算，前端直接讀 fin_grade）
ROIC×FCF/營收 矩陣 + 營益率加減號。與總表 fin_grade_1~5 同一套邏輯
營業收入~EPS群益損益表各科目（群益 zce/zcqa）
ROIC計算營業利益×(1-稅率) / (股東權益+有息負債-現金)
Dorsey/晨星標準版，排除槓桿效果
ROE / ROA計算稅後淨利 / 股東權益(總資產)
盈餘品質率計算營業現金流 / 稅後淨利（淨利為負不計算）
自由現金流計算營業現金流 + 資本支出（capex為負值）
配息率計算股利/EPS。EPS<=0但有配息→100%
後端 _calc_derived_fields 計算 payout_1~6 存 DB
BS/CF欄位群益資產負債表(zcpb)、現金流量表(zc3a)

架構原則 ▼
所有數據先計算存入 DB，前端一律從 DB 讀取，不可前端獨立計算。
正確模式：資料來源 → 後端計算 → 存入 DB → 前端從 DB 讀取
例外：互動式模擬工具（DDM、季度估算、評估法）使用者調參即時看結果，不存DB

衍生欄位由 recalc_all_derived() 統一計算存入 stocks 表（35個欄位），包含：
shen_eps/pe/yld/grade、weighted_*、blend_*、trailing_*、payout_1~6、
val_aa/a1/a2/a/lt6、est_eps/div/pe/yld/grade、sys_pe/yld/grade
