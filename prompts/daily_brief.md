# 逍遙投資日報速讀 — 產出指令

請幫我產出 {日期} 的逍遙投資日報速讀。

## 資料來源

從 DB 撈取當日資料：
1. **material_news**：`WHERE (date LIKE '{日期}%' OR created_at LIKE '{日期}%') AND tier >= 1`
2. **industry_news**：`WHERE created_at LIKE '{日期}%' OR pub_time LIKE '{日期}%'`
3. **體質佳清單**：`user_lists WHERE list_type='quality'`
4. **體質資料**：`stock_checklist`（pass_count、growth_signal、gi_pe、gi_yield、val_a、val_aa、red_flags）
5. **收盤價**：`stocks.close`

## 篩選邏輯

### 體質佳股票（優先判讀）
- 從 material_news + industry_news 中找出與體質佳股票相關的新聞
- 有以下訊號就寫進報告：
  - **成長動能**：營收創高、新產品、產能擴張、大單、法說上調展望、臨床進展、新領域切入
  - **價值動能**：庫藏股、大股東加碼、股利優於預期
  - **風險警示**：董監轉讓、減資、私募、財報重編
- **沒有新聞的股票不納入**，純估值訊號（如落入便宜區）不算

### 非體質佳股票
- 只有併購等級的重大訊息才納入（如股份轉換、合併、收購）

### 重大訊息（material_news）判讀規則
- tier 1 中性且內容為例行公告（董事改選、股東會修正、名稱變更）→ 跳過
- tier 1/2 且有實質內容（臨床結果、產能投資、併購、大額交易）→ 納入
- matched_rule 為「併購合併」→ 一律納入

## 輸出格式（Markdown）

每則 2-3 句精簡描述，標註股票代碼、體質項數、成長燈號、PE、評價位置。

```
# 逍遙投資日報速讀 {日期}（{星期}）

## 一、成長動能
（營收創高/新產品/產能擴張/大單/法說上調展望/臨床進展）

## 二、價值動能
（庫藏股/大股東加碼/進入便宜區/股利優於預期）

## 三、風險警示
（董監轉讓/減資/私募/財報重編）

## 四、總經產業摘要
（從 industry_news 整理重要總經與產業趨勢）

## 五、今日焦點整理
| 標的 | 訊號 | 體質/燈號 | PE | 評價位置 | 建議動作 |
```

### 評價位置判定
- 收盤 < val_aa → 很便宜
- 收盤 < val_a → 便宜區 A 內
- 收盤略高於 val_a → 略高於便宜價
- 收盤 >> val_a → 遠高於便宜價

### 注意事項
- 沒有值得寫的區塊就寫「無」，不湊字數
- 星期要正確（可用 `date -j -f '%Y-%m-%d' '{日期}' '+%u'` 確認）

## 儲存

完成後呼叫 `POST http://localhost:5000/api/ai-briefs`：
```json
{
  "date": "{日期}",
  "content": "報告內容（Markdown）"
}
```
