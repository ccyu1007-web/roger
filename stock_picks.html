前瞻性Neff 異動追蹤

▲
追蹤邏輯：比對起迄日期區間內，因營收公布或季報公布導致前瞻性Neff 組成要素改變的股票。純股價漲跌造成的變動不顯示。
觸發條件：營收公布 → 累積營收YoY改變 → 建議成長率g改變；季報公布 → 實際EPS更新 → 預估年EPS/股利D改變 → 預估PE與殖利率改變。
前瞻性Neff = (自訂成長率g + 預估殖利率) / 預估本益比 ｜ ≥ 1.0 表示成長性被低估，進入攻擊區。

使用流程：在每日價值評估選好 Tab + 篩選條件 → 按「複製分析指令」→ 貼給 Claude Code → 自動產出深度分析報告並存入此頁。

質性時效：3個月內 = 有效 → 可重倉｜超過3個月 = 待更新 → 最多小買｜無筆記 = 待研究
